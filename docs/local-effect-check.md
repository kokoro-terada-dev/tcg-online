# ローカル専用：効果画面を2ウィンドウで確認する

これは実カードの能力や正式な自動対戦ではありません。
固定のテスト動作「ホストが手札を1枚捨て、1枚引く」を既存のルームと画面で確認します。
起動時のフェーズ進行はフィクスチャです。実対戦の初期処理として使用しないでください。
固定テストでは実カードマスターを読み込みません。保存デッキとマスターのカード種類に
食い違いがあっても、このテストに限って初期化を妨げないようにしています。
画像・カードID・デッキ内の種類は保存デッキを使用し、実カードの能力や数値は検証しません。
通常のテストサーバーのマスター読込や、正式な効果エンジンの種類整合性検証は変更しません。

## 起動手順

1. VS Codeで `C:\Users\kensh\workspace_server` を開きます。
2. メニュー「ターミナル」から新しいターミナルを開きます。
3. 次を実行します。

```powershell
cd C:\Users\kensh\workspace_server
npm run dev:effects
```

4. サーバーのビルドが終わり、`LOCAL FIXTURE ONLY` とViteの `Local:` が表示されるまで待ちます。
5. `Local:` に表示されたURLをブラウザーで開きます。通常は `http://127.0.0.1:5189/` です。
   使用中のポートがある場合は別番号になるため、表示されたURLを使用してください。
6. 同じURLを別ウィンドウでも開きます。外部公開サイトのURLではありません。

## デッキと画像の準備

- 各ウィンドウでトップ画面から必要な画像ZIPを読み込みます。画像の読込状態はウィンドウ別です。
- このローカルURL上で使用できる保存済みデッキを用意します。
- 公開サイトや別ポートで保存したデッキは、ブラウザーの保存先が異なるため自動では出ません。
  必要なら従来のデッキ登録/読込操作で用意してください。
- 一方でデッキを追加した後、もう一方に反映されない場合は、対戦前に再読み込みします。

## 確認手順

1. 両ウィンドウでトップから「テスト対戦」へ進みます。
2. 一方で「ルーム作成」、もう一方で4桁コードを入力して「入室」します。
3. 両者ともデッキを選び終えてから、両者でREADYを押します。
4. ホストが「対戦開始」を押します。従来の盤面配置と効果パネルが表示されます。
5. ホストが「効果を使う」を押します。
6. 手札から支払い用の1枚を選び、「選択を確定」を押します。
7. 「実行」でそのカードがトラッシュへ移動します。
8. 「処理を進める」で1枚ドローし、「処理完了」になります。
9. 相手側では手札内容が裏向きのまま、枚数と公開トラッシュだけ更新されることを確認します。

「盤面を見る」で効果パネルをたたみ、自分のリーダーをタップすると、
固定テスト用の登録済み効果一覧を参照できます。ホスト側では「発動する」で
手札のコスト選択へ進めます。実カード本来の能力の一覧ではありません。

コード更新後は起動済みのターミナルでCtrl+Cを押し、`npm run dev:effects`を再実行してください。
両ブラウザーも再読込し、ルーム作成・入室からやり直します。
この起動方法ではバックエンドはソース変更だけでは自動再起動しません。

支払い前は「キャンセル」で未払いの状態へ戻せます。応答が不明なら「再同期」を押します。
処理完了後は、ホストのリーダーの一覧から同じ固定テスト効果を再度発動できます。
初期盤面からやり直すときは「ルームへ戻る」から再度READY/開始します。
通常の手動移動・手動アタックなどは、このテスト効果モードでは使用できません。

## 終了と安全境界

- 起動したターミナルでCtrl+Cを押すと、検証用フロントとバックエンドを終了します。
- ブラウザーを閉じるだけでは起動用プロセスは終了しません。
- バックエンドは空きポートを選び、127.0.0.1だけで待ち受けます。
- PC内の2ウィンドウ用です。iPhoneなど別端末からの接続やLAN公開は対象外です。
- NODE_ENV=productionでは起動を拒否します。
- VITE_TEST_SERVER_URLは起動したVite子プロセスにだけ渡します。.envやVercel/Render設定を変更しません。
- 通常のnpm run dev、公開サーバーの起動コード、実カードのマスター/効果登録は変更しません。

## 検証済み範囲

実Socketで入室から固定効果完了までを自動テストしています。
実ブラウザー2画面でも、入室/デッキ/READY/開始/未払いキャンセル/選択/支払い/ドローと
相手の手札非公開を確認しました。ブラウザー検証用の架空画像・HTML・スクリプト・結果画像は
local-data内のGit対象外ファイルです。実カード画像や利用者の保存データを変更していません。
