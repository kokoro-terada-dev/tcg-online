# EB05：複数枚の効果登場

隔離v3の `3.0.0-subset.53` で、手札を移動元とする `PLAY_BY_EFFECT` の `REPLACE_IF_FULL` に最大5枚の束縛を許可した。既存プロファイルの上限と、実際に1枚だけ選んだ場合の処理は維持している。

1. 操作者だけが手札から0〜N枚を登場順に選ぶ。0枚なら入れ替えを行わない。
2. 選択順に1枚ずつ登場する。満枠なら、その時点で場にいるキャラから入れ替えるカードを選ぶ。直前に登場したキャラも候補に含む。
3. 1枚ごとに必要なルール上のトラッシュ移動と登場を検証して反映する。ルールでトラッシュに置いたカードはKO扱いにしない。[公式総合ルール 3-7-6-1](https://www.onepiece-cardgame.com/pdf/rule_comprehensive.pdf?20250912=)
4. 元の効果が最後まで完了してから既存の誘発キューで解決する。同じ複数枚登場の途中で入れ替えられたキャラの登場時効果は発動しない。

入れ替えの順序は、ユーザーから提示された裁定で以前の実装を訂正した。山札・トラッシュを起点とする複数枚登場は対象外。

EB05-001・EB05-035・EB05-054の既存の未承認JSONはそのまま使用できる。今回の修正はRuntime側のみで、再生成なし。変更範囲の型検査は成功。今回の裁定修正後は指定どおりテスト・全体ビルドを実行していない。既存プロファイルのRegistry情報・既存定義・承認記録は変更なし。
