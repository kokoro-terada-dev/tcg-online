# EB05：複数枚の効果登場

隔離v3の `3.0.0-subset.53` で、手札を移動元とする `PLAY_BY_EFFECT` の `REPLACE_IF_FULL` に最大5枚の束縛を許可した。既存プロファイルの上限と、実際に1枚だけ選んだ場合の処理は維持している。

1. 操作者だけが手札から0〜N枚を選ぶ。0枚なら入れ替えを行わない。
2. 不足する枠数だけ、登場前に場にいたキャラを選ぶ。登場予定の札は入れ替え候補にならない。
3. 必要なルール上のトラッシュ移動と全キャラの登場をサーバーで検証し、成功時にまとめて反映する。ルールでトラッシュに置いたカードはKO扱いにしない。[公式総合ルール 3-7-6-1](https://www.onepiece-cardgame.com/pdf/rule_comprehensive.pdf?20250912=)
4. 登場時の観測を記録し、元の効果が最後まで完了してから既存の誘発キューで解決する。

同時選択で新規登場札を入れ替え候補に含めない点は今回の合意仕様。EB05-001固有の公式裁定を確認済みとは扱わない。山札・トラッシュを起点とする複数枚登場は対象外。

EB05のみ差分生成し、EB05-001・EB05-035・EB05-054の未承認JSONを出力した。完全生成42 → 45 / 61、残り16番号。Git管理外の `local-data/v3-eb05-batch-play/definitions` に定義、同フォルダの `set-holds.json` に残件を保存。新規3件のSchema・Compiler検証に成功。限定テスト50件成功（空き枠2／1／0、0枚、1枚、既存の1枚登場、誘発の待機、候補の秘匿を含む）。全回帰・全体ビルドは未実施。既存プロファイルのRegistry情報・既存定義・承認記録は変更なし。
