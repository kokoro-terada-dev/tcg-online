## 共通インターフェース

- `SOURCE.attachedDonCount`: 操作者の公開中のリーダー／キャラクターについて、個体と世代が一致する付与DON!!だけを読む。古い参照・不整合はUNKNOWN。アタック時の付与条件は発生時に確認する。
- `IS_SOURCE`: 継続効果の候補を発生源個体に限定する。同名の別個体は含まない。
- `PLAY_BY_EFFECT`: 自分の公開トラッシュを移動元に追加。単体の `REPLACE_IF_FULL` は、空き枠がなければ登場札を公開し、操作者が既存キャラを選んでルールでトラッシュに置く。退場と登場は両方成功してから反映し、退場はKOではなく、登場は既存のON_PLAY経路へ送る。[公式総合ルール 3-7-6-1](https://www.onepiece-cardgame.com/pdf/rule_comprehensive.pdf?20250912=)
- `TRASH_DECK_TOP`: 固定枚数または発動元の付与DON!!枚数まで、サーバー上で自分の山札上から公開トラッシュへ移す。事前閲覧・選択なし。既存の移動イベントとデッキ切れ判定を利用する。発動コストとしての山札破棄とは別。
- イベントMAINは既存の `LOOK_TOP` / `BOUND_CARDS` / `REVEAL` / `ORDER_CARDS` / `RETURN_TO_DECK` を再利用する。閲覧と選択は権限を持つ操作者のみ。相手への公開は選んだ札や公開領域へ移った札に限定する。
