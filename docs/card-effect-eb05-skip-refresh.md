# EB05-018：次回リフレッシュをスキップ

隔離v3 subset.57 の `SKIP_REFRESH` は、対象の個体・世代を保持し、次の相手ターンのリフレッシュで通常のアクティブ化からそのキャラだけを除外する。既存のターン境界で制限を消費する。カード効果によるアクティブ化や他カードのリフレッシュは変更しない。対象が場を離れて戻った場合、新しい世代には適用しない。

EB05-018 は登場時、相手のレストのコスト6以下のキャラを0〜1枚選ぶ。未承認JSONと残件は `local-data/v3-eb05-skip-refresh` に保存。EB05は完全生成52／61、残り9。限定型チェックおよび新規定義のSchema・Compiler検証に成功。対戦テストは未実施。
