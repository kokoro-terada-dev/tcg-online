## 保留と再開

EB05・OP17の残り96番号は `local-data/v3-priority-eb05-op17/set-holds.json` に、原文位置・理由・印刷値の要確認情報を保存。代表的な保留は、効果登場の複数枚選択、効果無効化、相手が選ぶモード、期限付き基礎値設定、置換、無指定の対象所属、パワー・コスト欄の「-」の扱い。未解釈は機能不足と断定しない。生成率は承認率・実戦利用可能率ではない。

`tools/generate-v3-draft-delta.js` の出力先の後に `EB05 OP17` のように弾を列挙すると、その弾の未生成だけを処理する。最新の `remaining-input.json` を次回の基準に指定すれば今回分も除外できる。今回の最終集計は `local-data/v3-priority-op16-eb04/set-progress.json`、未承認定義は各出力先の `definitions` に保存した。
