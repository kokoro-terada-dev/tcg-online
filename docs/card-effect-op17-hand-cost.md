# OP17：手札のキャラ自身のコスト補正

隔離v3 subset.61 は `CONTINUOUS_EFFECT.sourceZone: "hand"` で、手札の発生元個体自身のコストを下げられる。今回の条件は公開されている相手キャラの現在パワーに限定。条件がUNKNOWNなら登場コストを確定しない。場などへ移動した後は手札の補正を適用しない。

登場候補のコストと通常登場時のDON!!支払いには同じ算出処理を使う。OP17-005 は相手のキャラに現在パワー10000以上がいれば、印刷コスト10に対し6を支払う。単色リーダーの基礎パワーを8000にする登場時効果も、既存の基礎パワー設定と期限指定で生成した。同じ手札パターンのOP17-013も生成できた。

未承認JSONは `local-data/v3-op17-hand-cost/definitions`。OP17は完全生成71→73／119。型チェックと新規2枚のSchema・Compiler検証に成功。対戦テストは未実施。
