# PR26: 未解釈カード効果の構造・原因分析

## 分析の範囲

元CSVとPR24・PR25の全件トレースを照合し、PR25の未解釈3,341箇所を分析した。対象は生成不能1,744・部分生成514・未判定163の計2,421番号。CSV hash、Registry hash、カード番号、版hash、表示ID、原文位置の不一致は従来の検証で拒否する。対応対象は隔離v3の `3.0.0-subset.46`。各判定規則が根拠に使う既存命令名を対応一覧・実行プロファイルと照合する。

原文を、発動タイミング・条件・支払い・対象／選択者の手掛かり・数量／比較・操作・解決順序・持続期間に分け、原文とUTF-16位置を保持する。引用名や注釈の内部は命令として解析しない。たとえば「相手は」は明示主体の手掛かりであり、それだけで選択者を確定しない。構造署名と数値等を正規化した表現の2通りでグループ化し、どちらも影響番号数、箇所数の順で並べた。正規化は集計だけに用い、DSLは生成しない。

自動判定は全件 `automatic`。別途読み込んだ人手レビューは `human-reviewed` として別集計し、自動分類を上書きしない。今回の人手レビュー入力は0件。コードを確認して分類規則を作成したことと、各カードの意味確認・承認は別である。
