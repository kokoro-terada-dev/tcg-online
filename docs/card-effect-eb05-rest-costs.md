# EB05：カードをレストする発動コスト

subset.55 の `REST_AS_COST` は、既存の支払い選択を使って条件に合う自分のアクティブカード1枚をレストにする。相手のカード、レスト済みのカード、領域を移動した古い個体は支払いに使えない。イベント自体のDON!!支払いと追加支払いは別で、追加支払いを辞退・不能なら本文を解決しない。

- EB05-019：リーダー・キャラ・ステージ・アクティブDON!!から支払う。効果対象は指定特徴の自分のリーダーかキャラを最大1枚。
- EB05-020：指定名の自分のリーダーで支払い、2枚引く。

未承認JSONは `local-data/v3-eb05-rest-costs-reviewed-drafts/definitions` に保存。完全生成48→50／61。型チェックと新規2件のSchema・Compiler検証に成功。対戦テストは未実施。承認カタログは変更していない。
