## 生成器の変更

- 既存のモード選択と単一カード移動を使い、ライフやデッキの端からの1枚までの移動で「移動しない」を保持する。カードがない場合は移動せず、ライフの裏面を公開しない。
- 自分の手札1枚を山札の上・下へ置く処理と、手札から選んだカードだけを公開してライフへ移動する処理を追加した。回収後に残りを並べ替え、まとめて山札の上・下を選ぶ場合も、その順序を保持する。
- リーダーの状態・特徴と盤面の存在条件を組み合わせる。アクティブ／レストDON!!はコストエリアの該当状態だけを数える。既存キーワード付与や次の自分のターン開始までの期限、対象の任意性・数量を保持する。たとえば `EB05-044` はリーダーの特徴と相手のキャラの存在を両方確認し、相手リーダーのパワーだけを変更する。

## 残った未対応の原因

番号単位の集計。1枚に複数の原因がある場合は重複する。Aの件数は、カード全体ではなく既存命令で表せることを確認した未解釈の選択肢を含む番号。Bが0件なのは、今回の分類規則で確認した複合条件を実装した結果であり、全残件にBが存在しないという意味ではない。

| 分類 | 番号数 | 根拠・主なパターン |
| --- | ---: | --- |
| A | 3 | 1枚のライフ端移動の選択肢自体は `MOVE_LIFE` で表現可能。ただしイベントMAINのモード全体は対応外。 |
| B | 0 | 代表パターンのリーダー特徴と公開キャラ存在の連結は今回対応。 |
| C | 288 | 満枠でも可能な手札からの効果登場121、トラッシュからの効果登場56、事前閲覧なしの山札上から直接トラッシュ47、イベントMAINの非公開デッキ処理45。その他、シャッフル9、相手DON!!状態変更6、イベントMAINのモード4、バトル終了時誘発3、ダメージ置換1。機能別件数は重複する。 |
| D | 204 | 出典・版差・印刷情報など203、既知のSchema不一致1。 |
| 分類保留 | 1,466 | 規則で根拠を特定できなかった番号。A〜Dへ推測で割り当てていない。 |

満枠での効果登場には既存キャラをトラッシュに置く処理が必要だが、現在の `PLAY_BY_EFFECT` は空き枠を要求する。[公式カードQ&A](https://www.onepiece-cardgame.com/pdf/qa_op01.pdf?20220930=)。また、山札を直接トラッシュに置く処理に `LOOK_TOP` を流用すると、移動前に原文にない閲覧を行う。イベントMAINの `LOOK_TOP` は既存の許可リスト外。判定規則ごとに原文・番号・根拠を記録した。
