# PR22: DSL生成阻害要因と実装優先順位

## 対象と計数方法

公式CSVを既存のレビュー台帳生成器で再読込し、PR20/21の全件トレースと照合した。CSV・RegistryのSHA-256、カード番号、版の原文ペアhash、表示ID、元行、原文とUTF-16位置、集計件数のいずれかが一致しない入力は拒否する。対象はPR21の生成不能1,848、部分生成459、未判定160の計2,467番号。完全生成418は除外した。

「原文箇所」は同一番号・原文ペア・フィールド・位置で数える。同じ原文ペアの別イラストは二重計上せず、本文やトリガーが異なる版は別に数える。「台帳・印刷情報」は原文箇所とは別に、該当するカード番号を分類内で一度だけ数える。分類・機能の間では重複する。複数分類を持つのは448番号、複数の機能・原因ラベルを持つのは656番号。

自己登場と任意DON追加だけが検出された番号は、それぞれ37、32。これは検出ラベルの単独数であって、解決後に完全生成できる数ではない。優先順位は影響数だけでなく、変更範囲と誤判定リスクも考慮した。生成器のみのPR25と、下記のデータレビューは並行可能。

根拠：隔離v3の `dsl.ts`・`compiler.ts` の各命令契約、`fixtureCoordinator.ts` の実行前検査、`battle.ts`・`matchCoordinator.ts` の戦闘遷移、`replacementPlans.ts` の対象範囲、`movement/engine.ts` の並べ替え処理。[公式総合ルール §7-1-5、§8-1、§10-1-5](https://onepiece-cardgame.com/pdf/rule_comprehensive.pdf?20260109=)、[公式Q&A 全般（上限指定、ダブルアタック）](https://onepiece-cardgame.com/pdf/qa_rule.pdf)、[公式EB01 Q&A（選択者・条件の例）](https://asia-en.onepiece-cardgame.com/pdf/qa_eb01.pdf?20240126=)、[公式EB02 Q&A（自己登場とライフ枚数の例）](https://en.onepiece-cardgame.com/pdf/qa_eb02.pdf?20250425=)。これらで確認できないカード個別ケースは確定扱いしない。

## 印刷情報の独立レビュー

335番号の内訳は、版差・入力監査154と、現行定義が必須数値として要求する欄の非数値表記187（6番号重複）。後者はパワー欄が `-` の163、コスト欄が `-` の24。本文未解釈の番号にも存在するため、未判定160の内訳ではない。CSV欠損と公式表示そのものを区別し、根拠なしで `0` を補わない。PR20で同じ理由で未判定に移ったEB05-012も含め、データ確認は別のレビューとして進める。

| OP01-006 | 生成不能 | 0→1 | 全6表示IDが `-`。[公式OP01カード一覧](https://en.onepiece-cardgame.com/cardlist/?series=569101) |
| OP03-044 | 生成不能 | 0→1 | 全6表示IDが `-`。[公式OP03カード一覧](https://en.onepiece-cardgame.com/cardlist/?series=569103) |

4番号ともCSVの原文は変わっていない。PR21で本文を読み切れたことで初めて印刷値検査に進み、`printed-metadata-unconfirmed` で停止した。公式カード一覧も `-` を表示しているため、この4件をCSV抽出漏れとは扱わない。
