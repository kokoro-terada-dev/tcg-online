# OP17：同時退場の置換

subset.62 の `REPLACE_EVENT.group.filters` は、同じ効果の処理で退場するキャラから条件に合う自分のキャラをまとめて特定する。防ぐ元処理と代替処理を区別し、選択成立時にだけ公開する。対象外の移動は元の効果の処理として残る。

- OP17-015：相手の効果による同時退場を、発生元自身のKO一回に置き換える。発生元が同時KO対象に含まれていても、代替として一度だけKOする。KO時の手札支払いと自己登場も定義。
- OP17-023：指定特徴を持つキャラの同時KOを、発生元自身のレスト一回に置き換える。発生元がレスト済みなら置換できない。バトルKOにも接続。
