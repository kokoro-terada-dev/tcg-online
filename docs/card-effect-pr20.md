# PR20: 未解釈表現の分類とDSL案の拡張

## 分析と再現

同じCSV・監査台帳・Registryを使い、PR19の全件出力を基準にPR20の全件出力を比較した。カード番号、原文ペアhash、フィールド、UTF-16の開始・終了位置、原文が一致しないレポートは比較しない。分析ではNFKC、括弧表記、空白、数字のプレースホルダー化を使い、3,753箇所を2,713グループに集約した。正規化は集計専用で、DSL生成は元の原文に完全一致する定型だけを使う。

```powershell
npm --prefix server run build
node tools/generate-v3-drafts.js server/data/effects-v3-reviewed local-data/v3-review-ledger-pr00-20261029/source.csv local-data/v3-drafts-pr20-next --ledger local-data/v3-review-ledger-pr00-20261029/review-ledger.json
node tools/analyze-v3-draft-gaps.js local-data/v3-drafts-pr19-report local-data/v3-drafts-pr20-next local-data/v3-drafts-pr20-diff-next
```

実行済みの再生成結果とPR18集計は `local-data/v3-drafts-pr20-report/`、比較は `local-data/v3-drafts-pr20-comparison-final/`。比較の `gap-groups.csv` は出現数・カード番号数・代表原文・原因・表現可否、`card-diff.csv` はカード単位の生成・Compiler・対応分類の変更、`gap-diff.json` は集計と承認重複の理由を含む。出力はGit対象外。

## 追加パターンと影響

| 完全一致した原文パターン | 読めた箇所 | 影響カード番号 | うち完全生成へ移行 |
| --- | ---: | ---: | ---: |
| 相手キャラの現在コスト・パワー上限と枚数上限を指定するKO | 61 | 60 | 18 |
| 同じ条件でのレスト | 34 | 34 | 9 |
| カウンターで自分のリーダーだけにバトル中のパワー加算 | 31 | 30 | 0 |
| 既知の印刷キーワードに付く括弧注釈 | 3 | 3 | 1 |
| ライフトリガーから自身の一意なメイン本文を呼び出す | 3 | 3 | 3 |
| 相手キャラを上限条件付きで持ち主の手札へ戻す | 1 | 1 | 1 |

影響番号と完全生成への寄与はパターン間で重複する。対象の所有者・操作者・選択者、任意の上限、レスト条件、加算の持続期間をDSLに残す。注釈の改行も直前が同じ裸のキーワードなら扱えるが、実データで新たに該当したのは括弧表記3件。条件付きのキーワード付与の後に付く注釈や、単独の注釈は変換しない。メイン本文が複数・未解釈なら呼び出しも保留。印刷コストと効果本文を区別する既存のRuntimeを使用した。[公式総合ルール（プレイ・バトル・カード情報の用語）](https://en.onepiece-cardgame.com/pdf/rule_comprehensive.pdf)

ライフトリガーから自身を登場させる56番号は、既存の効果登場が手札に限定されるためPR18で明示的に未対応とした。その他の確認済み不足はシャッフル9、バトル終了時誘発3、被ダメージ置換1。手札不足を伴うドロー後の破棄、任意枚数のDON追加、条件付き付与は検証範囲外で、無条件・固定枚数の命令に置き換えていない。
