# EB05-046・048・049：基礎パワー、KO支払い、ブロッカー制限

- EB05-046 は手札を捨てた後にトラッシュを数える。条件成立時はリーダーの基礎パワーを現在ターン終了まで7000にする。印刷値は保持し、基礎パワーの設定が重なった場合は [公式総合ルール 4-9-2-1](https://www.onepiece-cardgame.com/pdf/rule_comprehensive.pdf?20250912=) に従い高い設定値を使う。別記の永続効果は印刷パワーを参照する。
- EB05-048 は追加のDON!!レストと、条件に合う自分のキャラのKOを同じ支払いとして確定する。解決時にコスト0の相手キャラ全員のブロッカー発動だけをこのターン中止める。
- EB05-049 は特徴で絞ったキャラのKO支払いをメイン・カウンターで共用する。支払いの移動は原因をコストとしつつKOとして記録し、KO時効果を元の効果解決後に処理する。

未承認JSONと残件は `local-data/v3-eb05-ko-stat-final`。EB05は57／61、残り4。限定型チェック、Schema、Compilerを確認。対戦テストは未実施。
