# EB05-021・029：期限付きの効果無効化と登場制限

隔離v3 subset.58 の `DISABLE_CARD_EFFECTS` は、選択したキャラの個体・世代に、現在ターンの終了まで制限を付ける。元の能力と、そのキャラを発生元にする誘発・継続効果・置換を無効化する。印刷情報や、他のカードが発生元の補正は消さない。場を離れたカードの新しい世代には制限を引き継がない。

`PREVENT_CHARACTER_PLAY` は、指定プレイヤーの現在ターン中のキャラ登場を止める。通常登場と効果登場の入口で判定し、ステージの配置は止めない。すでに登場したキャラの登場時効果は誘発できるが、その効果でも新たなキャラを登場させられない。

- EB05-021：2枚ドロー、最大1枚の効果登場、登場制限の順。アタック時は相手のキャラ最大1枚の効果を無効化。
- EB05-029：手札を捨てる任意支払いの後、対象の効果を無効化してから持ち主の手札に戻す。既存のライフトリガーを保持。

未承認JSONと残件は `local-data/v3-eb05-field-restrictions`。完全生成54／61、残り7。型検査、Schema、Compilerを確認した。対戦テストは実施していない。
