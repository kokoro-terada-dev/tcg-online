# PR19: 公式CSVから検証用DSL案を生成

## 使い方

```powershell
npm --prefix server run build
node tools/generate-v3-drafts.js server/data/effects-v3-reviewed local-data/v3-review-ledger-pr00-20261029/source.csv local-data/v3-drafts-next --ledger local-data/v3-review-ledger-pr00-20261029/review-ledger.json
```

- `--card EB01-005` のようにカード番号を指定して再生成できる。複数指定は `--card` を繰り返す。同じCSV・生成器・Registryなら、全件実行と個別実行で対象カードの案とハッシュは同じ。個別実行の生成集計は指定カードだけ、PR18集計は指定した案だけを投入した全CSVの数値。
- `candidates.json` はそのままPR18の `--candidates` に渡せる。CSV/原文ペアのSHA-256、カード番号、表示ID、生成器の版とコンパイル済みハッシュを照合できる。本文とトリガーは一切上書きしない。元CSVのSHA-256はオフライン案の出典として用い、承認用スナップショットのハッシュではない。
- `generation.csv` は生成分類・Compiler結果・未解釈箇所数の一覧。`generation.json` は別版ごとの原文、レコード番号、全箇所の判定、UTF-16の開始・終了位置、読めた命令と未対応の根拠を含む。PR18の `coverage.csv`、`summary.csv`、`summary.md` も同じディレクトリへ出力する。
- 出力は承認ディレクトリ外の新規フォルダのみ。今回の全件出力はGit対象外の `local-data/v3-drafts-pr19-report/`。

## 判定の範囲

- 1行全体が一致する定型のみ変換する。キャラの明示的な効果なし、既知の印刷キーワード（速攻、速攻：キャラ、ブロッカー、バニッシュ、ダブルアタック、ブロック不可）、指定済みのタイミングに続く無条件の「カードN枚を引く。」が対象。既知キーワードの括弧書きも、登録した完全一致だけを読み飛ばせる注釈として扱う。
- 本文とトリガーの全行を確認する。条件・対象・コスト・任意性・順序などが明示パターンから外れた行は、全文をUNKNOWNまたはPR18で確認済みの未対応機能として残す。読み取れた命令は追跡用の断片で、単独で発動可能とはみなさない。
- 完全生成には監査隔離なし、印刷情報確認、全行の解釈、Compiler成功、Runtimeプロファイル互換が必要。読めた行と未解釈行が混ざる場合は部分生成。読めた行がないかCompilerで止まる場合は生成不能。版差異・入力異常・印刷情報不足などは未判定。部分生成・生成不能・未判定からはカード全体のDSLを出力しない。
- 生成不能は機能不足の確定とは異なる。PR18の対応候補は意味未確認の案であり、部分生成もPR18の「一部対応」とは別指標。全出力を通じて新規承認は行わず、DSL案は `needs_review`、対戦での効果実行は未検証。

キーワードとトリガーの取り扱いは[公式総合ルール](https://www.onepiece-cardgame.com/pdf/rule_comprehensive.pdf?20260828=)の第6・7・10章と、既存のCompiler・Runtimeに照らした。カード番号固有の分岐、未確定裁定の確定、新規効果の実装は行っていない。

## 実データ

合成テスト後、効果なし、無条件ドロー、既存承認カード、未解釈行のあるカード、版差異を含む6番号で確認し、全CSVへ拡大した。

- 確認できた未対応機能: 効果によるデッキのシャッフル9、バトル終了時の誘発3、被ダメージの置換1。未解釈の行をこれらに推測で振り分けていない。
