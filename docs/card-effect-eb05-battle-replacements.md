# EB05-052・061：被ダメージと退場の置換

隔離v3 subset.60 の `REPLACE_EVENT` に、`DAMAGE` と `OPPONENT_LEAVE` を追加。

- EB05-052：リーダーの被ダメージを確定する前に、発生元キャラをトラッシュに置いて置換できる。ライフ0枚とダブルアタック全体に対応。トラッシュ移動はKOではない。既存のライフトリガーを保持した。
- EB05-061：印刷パワー上限、相手による退場、ターン1回を既存の置換判定に渡す。相手の効果による単体移動・KOとバトルKOに対応。自身も対象になり、ライフ0枚なら候補に出ない。置換確定時だけ使用回数を消費し、ライフのカード内容を選択肢に送らない。既存の登場時効果を保持した。

バトルの候補は防御側のみに公開。選択トークンは試合・バトル・操作主体・revision・候補に結び付ける。辞退時は既存のダメージ／KO処理へ進む。
